# Интерфейс кинотеатра

Серверные страницы на FastAPI и Jinja2 (ADR-24): каталог с обложками,
карточка фильма в духе IMDb и бронирование билетов на совместные просмотры.
Браузер ходит только сюда; сервис сам, параллельно, ходит во внутренние API —
Async API за фильмами, сервис бронирования за показами, сервис авторизации за
входом.

Открывается на http://localhost/ после `docker compose up`.

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Каталог: сетка обложек, жанры, поиск, страницы |
| `/films/{id}` | Карточка фильма: обложка, рейтинг, жанры, создатели; «Купить билет»: хост → дата и время → места |
| `/films/{id}?host={id}` | Та же карточка с выбранным хостом и его датами |
| `/screenings/new?film_id=` | Организовать показ |
| `/screenings/{id}` | Показ: бронь, изменение и отмена; для хоста — гости, правка и отмена; после показа — оценки |
| `/hosts/{id}` | Хост: рейтинг, отзывы, будущие показы |
| `/persons/{id}` | Персона и её фильмы |
| `/afisha` | Все будущие показы |
| `/me/bookings`, `/me/screenings` | Мои брони и моё расписание |
| `/login`, `/register` | Вход и регистрация через сервис авторизации |

Кнопка «Купить билет» есть только у полнометражных фильмов (`type = movie`).
Обложки — ссылки из каталога (ADR-25); у фильма без обложки — заглушка с
названием.

## Сессия и безопасность

* Токены сервиса авторизации — в cookie `HttpOnly`, `SameSite=Lax`; истёкший
  access-токен интерфейс обновляет сам по refresh-токену.
* Все изменения — POST с переходом после (PRG); POST с чужим `Origin`
  отклоняется (CSRF).
* Адрес возврата после входа — только путь своего сайта.
* Время в формах и на страницах — московское (`WEB_TIMEZONE`), в API уходит с поясом.

## Настройки

Префикс `WEB_`: `WEB_CATALOG_URL`, `WEB_BOOKING_URL`, `WEB_AUTH_URL`,
`WEB_API_TIMEOUT` (1 с), `WEB_TIMEZONE`, `WEB_COOKIE_SECURE`; ключ подписи —
`AUTH_JWT_SECRET_KEY`.

## Тесты

```bash
cd web/tests/unit && python -m pytest
```

Страницы проверяются на подменённых API: какие запросы уходят, с какими
заголовками и что видит зритель при ответах и отказах соседей.
