# Интерфейс кинотеатра

Сайт кинотеатра: каталог фильмов с обложками и поиском, карточка фильма,
бронирование билетов на совместный просмотр (хост → дата и время → места),
создание своего показа, кабинеты «Мои брони» и «Моё расписание», оценки после
показа, вход и регистрация.

Страницы собираются на сервере (FastAPI + Jinja2). Браузер ходит только сюда,
а интерфейс сам обращается к каталогу, сервису бронирования и сервису
авторизации.

## Запуск

Интерфейс поднимается вместе со всем стеком из корня репозитория:

```bash
cp .env.example .env
docker compose up -d --build
python3 scripts/seed_demo.py   # по желанию: хосты, показы и брони для демонстрации
```

Сайт открывается на http://localhost/.

Тесты:

```bash
cd web/tests/unit && python -m pytest
```
