# Сервис бронирования

Совместные просмотры. Хост создаёт показ: фильм, место, дату и время, число
мест. Гость выбирает хоста, затем дату и время и бронирует места; бронь можно
изменить или отменить до начала показа. Больше мест, чем есть у хоста,
забронировать нельзя — даже одновременными запросами. После показа хост и
гости оценивают друг друга. О бронях и изменениях участники получают письма.

Два процесса из одного образа: `booking-api` — HTTP API, `booking-relay` —
отправка событий о бронях в сервис уведомлений.

## Запуск

Сервис поднимается вместе со всем стеком из корня репозитория:

```bash
cp .env.example .env
docker compose up -d --build
```

Документация API — http://localhost/booking/api/openapi, префикс
`/booking/api/v1`. Читать показы можно без входа, всё остальное — с
access-токеном сервиса авторизации.

Тесты:

```bash
cd booking/tests/unit && python -m pytest
docker compose -f booking/tests/functional/docker-compose.yml up --build \
    --abort-on-container-exit --exit-code-from tests
```
